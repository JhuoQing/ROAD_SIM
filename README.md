# ROAD_SIM 道路車流模擬器

網頁版微觀道路車流模擬：上空視角、可在 OpenStreetMap 底圖上直接描出道路、即時指標。純前端單檔（Canvas 2D，無外部函式庫），電腦最佳，平板／手機可用。

👉 開啟 `index.html`，或部署後的 GitHub Pages 網址。

## 功能

**路網編輯**　畫路（自動產生路口與車道數變化）、拖曳節點、刪除、復原／重做；每條路可設每向車道數（1–3）、速限、單向。

**底圖**　可開 OpenStreetMap 圖磚並設定經緯度（支援貼上 Google 地圖／OSM 網址），直接照著真實路網描；也可改載入自己的圖片（航照、工程圖）並調整比例。

**路口型態**
- 讓行：左轉讓直行與右轉、先到先走。
- 號誌：A／B 兩個方向軸，各可設直行綠燈、**左轉專用相位**、**右轉專用相位**、黃燈、全紅、時差；可顯示倒數秒數。**紅燈（含右轉）一律停等**。
- 圓環：可調半徑，車輛逆時針繞行單一環道，進環車輛讓行環內車輛。

**車種**　小客車、**機車**、貨車，比例可調。機車靠車道右側行駛、會鑽過停等的小客車（不鑽貨車）、在有號誌路口做**兩段式左轉**（待轉區，可關閉）。

**指標**　車輛數、平均車速、通過量、平均延滯、旅行時間、待進車輛；時間序列圖；各路口流量／延滯／服務水準（LOS）／最大排隊長度。可匯出 CSV 與路網 JSON。

**快捷鍵**　`V` 選取、`R` 畫路、`S` 號誌／圓環、`X` 刪除、空白鍵播放暫停、`.` 單步、`[` `]` 調速、`F` 全景、`Ctrl+Z` 復原。

## 模型

- 跟車：IDM（Intelligent Driver Model），固定時間步長 0.1 s，固定亂數種子可重現。
- 換車道：MOBIL 型效益比較，含車道去向限制（左／右轉專用道）與車道縮減的強制換道。
- 路口：連接路徑為切線連續的三次貝茲曲線，轉彎速度由曲率決定；以時間間隙法判斷衝突點是否可通過。
- 延滯：實際旅行時間減去以速限行駛的時間；LOS 依路口平均控制延滯分級（號誌／無號誌各一套門檻）。

## 已知限制

- 圓環只有一條環道，approach 車道再多，環內仍只有一條車道。
- 每入口約 600 veh/h 以上的單車道號誌路口、3 車道縮成 1 車道的瓶頸會嚴重壅塞（已超過容量）。
- 無行人、無公車停靠、無路邊停車行為。

## 開發

```
src/sim.js        模擬核心（路網模型、幾何、IDM、號誌相位、圓環、機車；無 DOM）
src/app.js        介面、編輯器、底圖、繪圖
src/style.css     淺色主題
src/template.html 頁面骨架
python3 build.py  合併成單一 index.html

node test/sim.test.js    流量／車輛重疊（2D）／NaN 檢查，含圓環與機車情境
node test/red.test.js    闖紅燈（含紅燈右轉）檢查，違規數應為 0
node test/moto.test.js   機車兩段式左轉：待轉、放行、是否卡住
```
