# ROAD_SIM 道路車流模擬器

網頁版微觀道路車流模擬：上空視角、自行畫路、即時指標。純前端單檔（Canvas2D，無外部函式庫），電腦最佳，平板／手機可用。

## 玩法
- 直接開啟 `index.html`（或 GitHub Pages 網址）。
- 工具：選取 `V`／畫路 `R`／號誌 `S`／刪除 `X`；空白鍵播放暫停、`.` 單步、`[ ]` 調速、`F` 全景、`Ctrl+Z` 復原。
- 號誌：每個路口兩個方向軸（A／B），可設直行綠燈、**左轉專用相位**、**右轉專用相位**、黃燈、全紅、時差，可選擇是否顯示倒數秒數。**紅燈（含右轉）一律停等，不會闖紅燈**。
- 車道白色箭頭在畫面放大後自動顯示。
- 指標：車輛數、平均車速、通過量、平均延滯、旅行時間、待進車輛、各路口延滯／LOS／最大排隊。

## 開發
```
src/sim.js        模擬核心（IDM 跟車、換車道、路口衝突、號誌相位；無 DOM）
src/app.js        介面、編輯器、繪圖
src/style.css     淺色趣味主題
src/template.html 頁面骨架
python3 build.py  把以上合併成單一 index.html
node test/sim.test.js   流量／重疊／NaN 檢查
node test/red.test.js   紅燈違規（含右轉）檢查，違規數應為 0
```
